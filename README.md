# 🏋️‍♂️ FitLog

**FitLog** es una aplicación web Full-Stack diseñada para la gestión integral de entrenamientos personales, desarrollada bajo rigurosos estándares de calidad de software (**ISO/IEC 25010**). Cuenta con una arquitectura robusta, segura y una interfaz moderna con temática espacial y diseño *glassmorphism*.

---

## Tecnologías Utilizadas

### Backend
* **Java 17+**
* **Spring Boot** (Spring Data JPA, Spring Web)
* **Spring Security** (Autenticación y autorización)
* **JJWT (JSON Web Tokens)** para el manejo de sesiones seguras
* **MySQL** como base de datos relacional
* **Hibernate** (ORM)

### Frontend
* **React.js** (con Vite como empaquetador)
* **JavaScript (ES6+)**
* **CSS3** (Diseño personalizado con efectos de *Glassmorphism* y modo oscuro)

---

## 🛠️ Arquitectura y Estándares (ISO/IEC 25010)

El proyecto está estructurado bajo las siguientes características de calidad:
1. **Adecuación Funcional:** Flujo completo de registro, inicio de sesión seguro y gestión de usuarios.
2. **Seguridad:** Contraseñas protegidas, endpoints asegurados con filtros y emisión de tokens JWT firmados criptográficamente.
3. **Usabilidad:** Interfaz intuitiva, diseño responsivo oscuro, validaciones en tiempo real y feedback visual claro para el usuario.
4. **Mantenibilidad:** Separación clara de responsabilidades (MVC en backend, componentes modulares y servicios independientes en frontend).
